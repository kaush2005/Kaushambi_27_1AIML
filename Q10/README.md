# Q10 – Express CRUD with MongoDB

1. Install and start MongoDB Community Server.
2. In this folder run `cd backend`, `npm install`, `npm start`.
3. Open http://localhost:3010.

Default database: `fullstack_q10` at `mongodb://127.0.0.1:27017`. Set `MONGO_URI` if your database uses another connection string. REST endpoints: `/api/products` (GET/POST) and `/api/products/:id` (GET/PUT/DELETE).
