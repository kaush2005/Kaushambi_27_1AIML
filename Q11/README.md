# Q11 – E-commerce Application

1. Start MongoDB Community Server.
2. Run `cd backend`, `npm install`, `npm start`.
3. Open http://localhost:3011.

Features: product listing, cart quantity controls, demo checkout, order history and seller panel to add/edit/delete products. The checkout is simulated for academic demonstration; it does not connect to a real payment gateway or charge money. Default MongoDB database: `fullstack_q11`.
