# Q9 – Express RESTful CRUD

Run `npm install` and `npm start`; server: http://localhost:3009.

Endpoints: `GET /api/products`, `GET /api/products/:id`, `POST /api/products`, `PUT /api/products/:id`, `DELETE /api/products/:id`. Send JSON `{ "name": "Tablet", "price": 12000, "description": "Android tablet" }` for create/update. Data is in memory and resets on restart. Test with Postman or Thunder Client.
